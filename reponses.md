# Réponses du mini-TP

## Partie A — Environnement

- Node.js permet d'exécuter JavaScript en dehors du navigateur.
- npm permet de gérer les scripts et les dépendances d'un projet.
- Git suit les modifications du code.
- GitHub héberge le dépôt distant.

## Partie B — Structure web

- HTML définit la structure et le contenu des pages.
- CSS gère la présentation et l'adaptation aux écrans.
- Les media queries permettent d'adapter l'affichage aux différentes largeurs.

## Partie C — Requêtes HTTP

- GET sert à récupérer une ressource.
- POST sert à envoyer des données au serveur.
- Un code HTTP 200 indique que la requête a réussi.
- Un code HTTP 404 indique que la ressource n'a pas été trouvée.

## Partie D — Manipulation des données

Les fonctions de recherche, de tri et de statistiques utilisent notamment `filter`, `map`, `reduce`, la destructuration et l'opérateur spread.

## Partie E — Programmation asynchrone

La fonction `chargerEtudiants` utilise `fetch` et `async/await`. Les erreurs de récupération sont interceptées avec `try/catch`.
